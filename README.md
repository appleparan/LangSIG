## LangSIG

[![Read the Docs](https://readthedocs.org/projects/lang-sig/badge/?version=latest)](https://lang-sig.readthedocs.io/en/latest/)

#### 사용법 1 ([uv](https://docs.astral.sh/uv/) 사용)
- $ uv sync --frozen
- $ uv run mkdocs build

#### 사용법 2 (`pip` 사용)
- $ pip install -r docs/requirements.txt
- $ mkdocs build
